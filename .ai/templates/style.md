# Study Stack — UI & Brand Style Guide

## Product Vision

Study Stack is a playful, modern learning platform that helps K–12 teachers create engaging flashcard decks and interactive study experiences for students. The app should feel:

- Fun without feeling childish
- Safe and encouraging
- Easy for teachers to manage
- Rewarding and game-like for students
- Accessible across age groups (Kindergarten through High School)

The visual identity should blend educational trustworthiness with the excitement of modern games and social apps.

# Overall Design Direction

## Core Experience Principles

### 1\. Gamified Learning

The UI should feel motivating and rewarding.

Use:

- XP bars
- Achievement badges
- Daily streaks
- Progress rings
- Celebration animations
- Friendly mascot moments
- Confetti micro-interactions

Avoid:

- Cluttered educational dashboards
- Corporate LMS-style interfaces
- Dense text-heavy layouts

### 2\. Age-Adaptive Design

The UI should subtly adapt based on grade level.

#### K–5 Experience

- Larger buttons
- More illustrations
- Softer rounded corners
- Bright colors
- More animations
- Friendly iconography
- Voice and audio support

#### Middle School Experience

- Slightly more polished/game-like
- Competitive elements
- Progress systems
- Custom avatars
- More dynamic layouts

#### High School Experience

- Cleaner modern aesthetic
- Minimalist layouts
- Productivity-oriented UI
- Reduced animation intensity
- Sleek gradients and dark mode support

# Layout & Spacing

## Design Language

### Corners

Use large rounded corners.

- Cards: 20–28px radius
- Buttons: pill-shaped or 16–24px radius
- Inputs: soft rounded fields

### Shadows

Soft layered shadows.

Avoid:

- Heavy hard shadows
- Sharp edges
- Harsh outlines

### Spacing

Use generous spacing.

Students should never feel overwhelmed.

Recommended:

- 8px base grid
- Large whitespace zones
- Clear content hierarchy

# Main Screens

# 1\. Student Home Screen

## Goal

Immediately communicate:

- Progress
- Motivation
- What to study next

## Layout

### Top Section

- Greeting (“Welcome back, Maya!”)
- Streak counter
- XP level
- Avatar/profile bubble

### Bottom Section

- Large featured Continue Studying card (last played deck) if user is returning. First time user should get brief game instructions prompt.
- Choose a new deck: opens modal with filterable list of decks grouped by category

## Visual Feel

- Vibrant gradients
- Floating icons
- Animated stars/confetti
- Dynamic illustrations

# 2\. Flashcard Study Screen

## Core Experience

This is the most important screen in the app.

It should feel immersive and highly interactive.

## Card Design

### Flashcard Appearance

- Large centered card
- Slight 3D elevation
- Rounded corners
- Swipe animations
- Smooth flipping transitions

### Front Side

- Large readable text
- Optional illustration/image
- Audio button
- Fun accent icons

### Back Side

- Answer reveal animation
- Optional explanation
- Emoji reactions
- Confidence rating buttons

## Study Interactions

### Swipe Controls

- Swipe right = “I know this”
- Swipe left = “Need practice”

### Feedback

- Tiny celebration animations
- XP popups
- Sound effects
- Sparkle transitions

# 3\. Teacher Dashboard

## Design Goals

Teachers need:

- Simplicity
- Fast deck creation
- Clear analytics
- Easy classroom management

The teacher side should feel:

- Clean
- Organized
- Professional but approachable

## Layout

### Sidebar Navigation

- Dashboard
- My Decks
- Students
- Assignments
- Analytics
- Settings

### Main Dashboard

Cards showing:

- Student engagement
- Completion rates
- Top performers
- Deck usage
- Recent activity

### Deck Builder

A clean card-based editor.

Include:

- Image upload
- AI-assisted flashcard suggestions
- Color-coded categories
- Real-time preview

# 4\. Deck Library Screen

## Visual Style

This should feel like browsing collectible card packs.

Each deck should appear as:

- A colorful card pack
- Subject-themed artwork
- Progress completion overlay
- Difficulty indicators

## Categories

Use fun visual coding:

- Math = Blue
- Science = Green
- History = Orange
- Language Arts = Purple
- Geography = Teal

# Motion & Animation

## Animation Style

Smooth and rewarding.

### Recommended Interactions

- Card flips
- Hover bounce
- XP particle bursts
- Achievement unlocks
- Progress filling animations
- Button spring effects

### Avoid

- Excessive motion
- Distracting animations
- Long transitions

Animations should feel fast and satisfying.

# Accessibility

## Requirements

### Readability

- High contrast text
- Dyslexia-friendly spacing
- Large tap targets
- Adjustable font sizes

### Inclusivity

- Colorblind-safe indicators
- Audio support
- Keyboard navigation
- Screen reader compatibility

### Learning Support

- Read-aloud functionality
- Simplified focus mode
- Reduced distraction mode

# Audio Design

## Sound Style

Friendly and lightweight.

Include:

- Soft reward chimes
- Card flip sounds
- Achievement unlock effects
- Positive reinforcement tones

Avoid:

- Loud arcade sounds
- Annoying repetitive audio
